# 초기 탐색 실험 메모 (최종 결과 아님)

## 두 Schoolbook의 차이

- 기본형(immediate): 블록 곱셈을 할 때마다 자리올림을 계산한다.
- 지연형(deferred): 곱셈 결과를 누산 배열에 모은 뒤 자리올림을 한꺼번에 계산한다.
- 길이가 각각 n블록인 비영 입력에서 두 방식은 모두 n²번의 블록 곱셈을 수행한다. 기본형은 내부 자리올림 계산을 n²번, 지연형은 2n번 수행한다. 이 숫자는 CPU 명령어 횟수가 아닌 코드 수준의 반복 횟수다.
- 지연형은 64비트 부호 없는 누산 배열을 추가로 사용한다. 기수 B=10000일 때 min(n,m) ≤ UINT64_MAX / [B(B−1)] 조건을 적용해 누산값과 이전 자리올림의 합이 표현 범위를 넘지 않도록 검사한다.
- 상수로 나누는 연산은 컴파일러가 다른 기계 명령으로 최적화할 수 있으므로, 소스에 나타나는 나눗셈 횟수를 실제 CPU 나눗셈 명령 수와 동일하게 해석하면 안 된다.

## Toom-3 보간

곱 다항식 C(x)=c0+c1*x+c2*x²+c3*x³+c4*x⁴에 대해 v0=C(0), v1=C(1), vm=C(-1), v2=C(2), v∞=c4로 둔다.

- c0=v0, c4=v∞
- c2=(v1+vm)/2−c0−c4
- s=(v1−vm)/2=c1+c3
- c3=(v2−c0−4c2−16c4−2s)/6
- c1=s−c3

정수 나눗셈의 나머지가 0인지 검사한다. 재귀 곱셈은 절댓값을 분할하고 반환 시 부호를 복원한다.

## 다음 연구 단계

메모리 할당과 단계별 비용을 계측하고, 한 단계 분할 실험으로 성능 역전의 원인을 분석한다. 두 Schoolbook 방식에 맞는 임계값을 별도로 탐색하고 독립 입력으로 검증한다. 최종 실행 시간은 학생 컴퓨터에서 측정하며, 이론 모델과 실제 데이터의 관계를 설명한다. 기능 추가, 오류 수정 및 검증 등 실제 작업 단위로 커밋을 남긴다.

## 실험 3 설계 (v0.2)

- H1: 재귀 말단이 작을수록 자리올림 지연의 이득이 줄어드는가? 독립 Schoolbook의 크기별 시간 및 실제 말단 길이 분포를 함께 관찰한다.
- H2: 기초 비용을 줄였을 때 나머지 구간의 상대적 비중이 커지는가? 분할, 평가, 보간, 재조합, 미분류 비용을 별도 실행에서 측정한다. 비율 상승만으로 절대 시간이 증가했다고 해석하지 않는다.
- H3: 기초 연산 방식에 따라 전환 임계값이 변하는가? 이후 단일 분할 및 임계값 탐색 실험에서 확인한다.
- 모델: 말단 길이별 호출 횟수와 독립 측정 시간의 가중합으로 기초 연산 가속률 r을 구하고, 개선 전 계측 실행의 기초 시간 비율 p로 1/((1-p)+p/r)을 예측한다. 일반 실행의 실측과 비교한다. 실제 캐시 상태, 객체 수명, 계측 오버헤드 차이 때문에 오차가 있을 수 있다.
- 네 컴퓨터에서 얻은 결과와 실제 실행 화면을 보고서에 사용한다. 개발 환경의 탐색 데이터는 최종 결론으로 사용하지 않는다.

## 실험 4~6 설계 (v0.3)

학생 PC의 v0.2 화면에서 4096 limb Schoolbook의 가속률은 3.51배였으나 고정 임계값 Karatsuba의 가속률은 1.00배였다. 512 limb에서는 0.90배였다. 4096 limb Immediate Karatsuba의 기초 비용 비중은 26.6%, 분할 21.3%, 재조합 29.0%였다. 이 수치는 계측 실행의 근사치이며 원인 확정이 아니다. 작은 연산의 100ns 단위 측정은 해상도에 민감하여 다음 실험에서 묶음 타이밍을 사용한다.

단일 분할에서는 균등 분할과 평가값 길이 증가 무시라는 근사하에 Karatsuba의 이차항 절감이 1/4, Toom-3의 절감이 4/9이다. 기초 곱셈의 이차항 계수가 작아지면 절약되는 절대 시간이 줄어들므로, 나머지 비용이 동일할 경우 역전점은 뒤로 이동할 것으로 예상한다. 실제 평가값 길이와 비선형 비용이 있어 이 예측은 검증 대상이다. 단일 분할의 역전 관측 구간과 전체 재귀에 적용할 임계값을 구분한다.

임계값을 각 베이스에서 별도로 탐색하고 독립 시드에서 검증한다. Hybrid가 이기지 못할 경우 중간 분할의 추가 비용, 후보 선택의 변동성, KT=TT 여부를 함께 확인한다. 원본 데이터를 보존하고 임계값을 보편적 상수로 일반화하지 않는다.

## v0.4 — 학생이 제시한 쟁점의 심화

- 실험 3: 4096 limb Immediate에서 K 분할+재조합 50.3%, T 보간 30.1% (계측 비중). 각각만 변경하여 실제 전체 시간과 해당 구간 시간의 변화가 일치하는지 본다. 암달식 S=1/(1-p+p/r)는 해당 구간만 빨라지고 나머지가 동일하다는 가정의 예측이다.
- 실험 6: Immediate의 H=(128,128)은 K 구간 없음. Deferred의 H=(256,512)은 K 구간 있음. 순수 T의 TT와 H의 TT가 다르면 K 삽입의 효과만 비교할 수 없다. TT 고정, KT 변경으로 K 삽입 손익 B0-B1-(O1-O0)을 측정한다. K 실제 방문이 없는 입력은 분리한다.
- 실험 4~5: 기존 관측 격자에서 K의 A/B는 모두 128~192, T의 A는 128~192, B는 256~384. 이는 정확한 역전점의 동일성을 의미하지 않는다. 세밀한 격자와 입력별 분포로 재측정한다. 선택된 KT는 A 256/B 512로 달랐다.
- v0.4 정규 결과는 학생 PC에서 확보할 예정이다. 개발 환경의 축소 실행은 검증용이며 보고서 실측 수치로 사용하지 않는다. 원본과 환경, 실제 화면을 함께 보존한다. 장단점과 발전 방향은 관찰·가설·통제 실험을 연결해 작성한다.
