# AI 사용 기록 (초안, 실제 작업에 맞춰 계속 갱신)

- 2026-11-24: ChatGPT에 중간 발표 자료 및 과제 안내서를 바탕으로 연구 설계, 평가 기준, 실험 설계와 구현 환경을 함께 정리해 달라고 요청했다. 학생은 기존 주제 유지, 원인 중심 분석, 실험 3~6 중심, 한국어 README, 유연한 일정 및 구현 우선이라는 방향을 정했다.
- ChatGPT는 공통 C++17 큰 정수 표현, 두 Schoolbook 구현, Karatsuba, Toom-3, 하이브리드, 분리된 계측 빌드, Python 독립 검증 및 초기 벤치마크 스크립트의 첫 버전을 작성했다. 개발 환경에서 정확성 테스트와 초기 측정을 수행했다.
- 검증 중 음수 평가값을 강제할 예시의 실제 분할 크기를 확인하고, Toom-3 재귀 진입 및 의도한 분할이 일어나도록 입력을 수정했다. 학생의 코드 검토와 로컬 실행은 아직 수행되지 않았다.
- 이 문서는 작업 기록 초안이다. 학생이 실제로 검토·수정한 사항과 최종 판단, 추가 AI 질의·응답을 사실대로 추가해야 한다.

- 2026-11-24: 학생이 설명 문서의 한국어 작성, Windows VS Code 환경 설정 안내, 원본 데이터와 핵심 분석 결과의 분리, 실제 작업 단위의 잦은 커밋을 요청했다. ChatGPT는 한국어 실험 메모를 작성하고 README의 Windows 빌드 절차를 구체화했다. 알고리즘과 초기 측정 데이터는 변경하지 않았다.

- 학생은 Windows 개발 도구를 설치하고 VS Code에서 프로젝트를 열어 GitHub 공개 저장소를 생성 및 첫 커밋했다. 로컬에서 v0.1 정확성 검증 4,816건이 통과했다고 확인했다. 실제 실행 화면 캡처를 보고서에 포함할 것을 요청했다.
- 다음 단계에서 ChatGPT는 H1(말단 크기별 개선율), H2(비용 구성), H3(임계값 변화)를 제안하고, v0.2의 구간별 시간 계측·말단 분포·독립 미세 벤치마크·암달 모델 비교를 구현했다. 일반 및 시간 계측 실행 파일의 정확성 테스트를 재실행하고, 개발 환경에서 실험 스크립트를 시험했다. 타이머 삽입 및 임시 객체 수명 변경의 한계를 문서화했다. 학생의 v0.2 로컬 측정 결과는 아직 확인하지 않았다.
